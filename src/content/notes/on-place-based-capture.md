---
title: Place is a filing system nobody maintains
date: 2026-07-28
kind: design
project: kubli
---

Every organizational scheme I've built for notes has eventually collapsed
under its own maintenance cost. Tags rot. Folders multiply. Inboxes become
landfills.

Location is different. You never have to file anything by place — you were
already somewhere when the idea arrived. The metadata writes itself, and it
matches how memory actually indexes: *I thought of that on the walk by the
reservoir.*

Kubli's whole bet is that this free, self-maintaining index is enough
structure for a capture tool. So far the bet is holding.
