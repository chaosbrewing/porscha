# Brand assets

| File | Use |
| --- | --- |
| `porscha-mark.png` | The copper P symbol on its own. This is the mark the site uses — footer colophon, and anywhere a small emblem is wanted. |
| `porscha-logo.png` | The original full lockup. **Not rendered anywhere on the site.** |
| `obra-mark.jpg` | The OBRA mark, gold leaf on black. Used on ART. |

`porscha-mark.png` is a square crop of the monogram out of
`porscha-logo.png`, deliberately excluding the wordmark and the line
beneath it — that line reads "ART. APPS. STORIES. ORIGINS.", which is
retired positioning. The current identity is:

```
POR$CHA
Founder • Artist • Builder

ART • APPS • HEADQUARTERS
```

Both copper files are photographed on white and have no alpha channel,
so they are shown on an explicit ivory plate rather than knocked out.
`obra-mark.jpg` is photographed on black and carries its own dark
ground.

If a version of the mark with transparency ever exists, drop it in as
`porscha-mark.png` (same square framing) and the plate can go.
